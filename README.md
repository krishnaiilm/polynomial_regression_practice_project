# Polynomial Regression Practice 📈

## 📌 Overview
This project demonstrates the implementation of **Polynomial Regression**, a type of regression analysis used to model nonlinear relationships between variables.

The notebook shows how linear regression can be extended using polynomial features to better fit curved data.

---

## 🎯 Objectives
- Understand the concept of polynomial regression
- Compare linear vs polynomial models
- Visualize model fitting on data
- Improve prediction accuracy for non-linear datasets

---

## 🛠️ Technologies Used
- Python 🐍
- Jupyter Notebook
- NumPy
- Matplotlib
- Scikit-learn
